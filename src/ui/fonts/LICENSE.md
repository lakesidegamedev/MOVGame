# Flag font licence

`mov-flags.woff2` is a subset of the "Twemoji Country Flags" font, itself a subset of
[Twemoji Mozilla](https://github.com/mozilla/twemoji-colr). It holds only the 14 flags the game uses
(Australia, Brazil, Canada, France, Germany, India, Ireland, Italy, Japan, Mexico, New Zealand, Spain,
United Kingdom, United States). Rebuild it with `scripts/subset-flag-font.py`.

- Flag artwork: Twemoji, copyright Twitter, Inc and other contributors, licensed under
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The artwork was cropped, converted to a
  colour font and subset; no other change was made to the designs.
- Font tooling (Twemoji Mozilla): Apache License 2.0, Mozilla Foundation.
- Packaging of the source font: `country-flag-emoji-polyfill` by TalkJS, MIT.

Redistribution is allowed under all three licences provided this attribution travels with the font.

# Fira Sans

`fira-sans-400.woff2` to `fira-sans-700.woff2` are Fira Sans (regular, medium, semibold, bold), the
typeface of the Lakeside Games store. The Store panel uses them so it matches the Lakeside store pages.
Copyright The Mozilla Foundation and Telefonica S.A., licensed under the SIL Open Font License 1.1;
the full licence is in `fira-sans-OFL.txt`, which travels with the fonts.
